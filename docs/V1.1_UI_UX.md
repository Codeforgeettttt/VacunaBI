# VacunaBI — Especificación y avance V1.1 (UI/UX)

**Fecha:** 2026-11-16  
**Estado:** En desarrollo; pendiente de validación visual en navegador y escritorio.  
**Documento de referencia:** plan maestro de versiones V1.0 → V2.0 del equipo.

## Objetivo

Transformar la página única y extensa de la V1.0 en una interfaz modular, consistente y accesible, sin modificar los cálculos del ETL ni la estructura de salida de `etl.py`.

## Implementado en la primera iteración

| Requisito | Implementación |
| --- | --- |
| Navegación modular | Menú lateral con cinco vistas mediante fragmentos URL (`#resumen`, etc.). |
| Resumen ejecutivo | Cuatro KPI existentes y las dos series históricas/mensuales. |
| Localidades | Ranking de primera infancia y matriz de calor agrupados en una vista. |
| Sectores y biológicos | Comparaciones institucionales y por grupo de biológico. |
| Calidad de datos | Tabla de registro ETL y explicación de sus limitaciones. |
| Metodología | Descripciones de cobertura, brecha, etapas y procedencia de datos. |
| Identidad visual | Tema oscuro refinado, tipografía de sistema y componentes con espaciado consistente. |
| Responsividad | Navegación horizontal en ventanas reducidas y cuadrículas adaptables. |
| Accesibilidad inicial | Salto a contenido, etiquetas de regiones, foco visible y soporte de movimiento reducido. |
| Integración de gráficos | Preservación de IDs del HTML, marcadores de inyección y ajuste de tamaño al navegar. |

## Componentes de diseño

- `.app-shell`: estructura de navegación y contenido.
- `.sidebar`, `.nav-link`: navegación entre vistas.
- `.topbar`: título del proyecto, estado y fecha de origen.
- `.page`, `.dashboard-grid`: secciones y rejillas de contenido.
- `.card`, `.kpi`: contenedores comunes de indicadores y gráficos.
- `.data-note`: mensajes metodológicos y advertencias.
- `.info-grid`: secciones de documentación.

Los colores y espaciados se definen mediante tokens CSS `--page`, `--surface`, `--primary`, `--ink` y otros. El modo claro se reservará para la V1.5.

## Comportamiento de navegación

1. Cada enlace cambia el fragmento de URL.
2. El script `renderNavigation()` oculta vistas no seleccionadas.
3. El enlace activo tiene `aria-current="page"`.
4. Se actualiza el título de la ventana.
5. Los gráficos de Chart.js se redimensionan después de mostrar su sección.
6. La página inicial es `#resumen`, si no existe una ruta reconocida.

No se han añadido filtros globales: esos corresponden a V1.2.

## Protección de la base

- No se cambian los indicadores ni el código de `etl.py`.
- Se conservan los identificadores `k1` a `k4`.
- Se conservan `cAnual`, `cActual`, `cLoc`, `cInst` y `cGrupo`.
- Se conservan las tablas `heat` y `log`.
- Se mantienen los marcadores `/*__CHARTJS__*/` y `/*__DATOS__*/null`.

## Pruebas

Ejecutar:

```bash
python test_etl.py
python -m unittest -v test_etl_regression test_dashboard_template
```

La suite de interfaz valida estructura de vistas, navegación, identificadores, marcadores ETL, semántica básica y redimensionado de gráficos. No sustituye las pruebas de visualización real en un navegador.
